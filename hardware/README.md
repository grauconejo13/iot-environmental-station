# Hardware

This directory will contain the station bill of materials, verified Le Potato pin assignments, wiring diagrams, and build photos.

## Planned v1

- Libre Computer AML-S905X-CC (Le Potato)
- BME280 temperature / humidity / pressure sensor
- BH1750 ambient light sensor
- Breadboard
- Jumper wires
- microSD card
- Stable power supply

## Rule for hardware documentation

Pin numbers and wiring instructions should only be documented here after they are verified against the exact board and sensor modules used in the physical build.
